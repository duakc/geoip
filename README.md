# geoip

自定义 GeoIP 规则集，每日自动更新，发布在 [`release`](https://github.com/duakc/geoip/tree/release) 分支。

| 代码 | 说明 |
| --- | --- |
| `cn` | 中国大陆 |
| `cn-cm` | 中国移动 |
| `cn-ct` | 中国电信 |
| `cn-cu` | 中国联通 |
